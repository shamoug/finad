Download Finad

Free. The desktop app does the work and the phone app brings the alerts with you. Both update themselves from this website.

🖥️ Windows (10 or 11, 64-bit)

The desktop app reads the news, scores the stocks and raises the alerts. It starts with Windows and keeps working from the system tray.

Download Finad for Windows
Finad-Installer.zip
  1. Unzip the download.
  2. Double-click install.bat. No admin rights are needed; it downloads the app runtime (about 110 MB) once.
  3. Finad opens, adds Start Menu and Desktop shortcuts, and starts with Windows from then on.

Optional: install Ollama and run ollama pull qwen3:4b-instruct so a local AI also reads the headlines.

📱 Android (7 or later)

Your signals, alerts, world drivers and news, with a notification for every new sell or buy alert.

Download Finad for Android
Finad-Android.apk
  1. Scan the code with your phone's camera, or open this page on the phone, and download the app.
  2. Open the file. Android asks once to allow installing apps from your browser.
  3. In Finad on your computer, open Phone and turn on the phone link. Then tap Scan QR code in the app.

Quicker: the QR code on Finad's Phone page does both. Scan it with the phone's camera and it installs the app, then links it. The app updates itself after that.

Checksums

The apps check these before installing an update. To check a download yourself in PowerShell: Get-FileHash Finad-Installer.zip.

Uninstall

Windows: Settings → Apps → Finad → Uninstall. Your data stays in %USERPROFILE%\.finad until you delete that folder. Android: uninstall like any other app.
